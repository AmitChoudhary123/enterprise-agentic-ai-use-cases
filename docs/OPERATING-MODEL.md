# Operating Model

Enterprise agentic AI requires shared ownership across business, technology, platform, and risk teams.

## Roles

| Role | Accountability |
| --- | --- |
| Business sponsor | Outcome and adoption |
| Product owner | Workflow fit and prioritization |
| AI architect | Agent pattern and integration design |
| Context owner | Knowledge quality and freshness |
| Risk partner | Controls and approval rules |
| Evaluation lead | Test set and release gates |
| Platform owner | Tooling, observability, and runtime standards |

## Cadence

- Weekly delivery review
- Biweekly architecture and governance review
- Monthly portfolio review
- Quarterly autonomy and risk review
