# Lessons Learned

## 1. Autonomy is not the goal

The goal is business leverage with control. Some high-value workflows should remain recommendation-only until context and governance mature.

## 2. Reversibility matters

Reversible actions can tolerate more autonomy. Material or irreversible actions need approval, audit, and escalation.

## 3. Context readiness limits ambition

An agent cannot reliably act when enterprise knowledge is stale, contradictory, or unowned.

## 4. Risk teams should join before tool access is designed

Agentic AI risk is shaped by tools, authority, action, and workflow state. Late governance review misses the design moment.

## 5. Portfolio sequencing beats isolated enthusiasm

The enterprise should scale patterns, not one-off agent demos.
