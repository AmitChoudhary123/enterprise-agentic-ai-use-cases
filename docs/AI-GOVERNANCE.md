# AI Governance for Agentic Use Cases

Agentic AI governance should be tied to autonomy level and business impact.

## Governance model

| Autonomy | Governance requirement |
| --- | --- |
| L0 observe | Logging and feedback |
| L1 recommend | Human decision ownership |
| L2 prepare | Human approval before execution |
| L3 reversible execution | Authorization, audit, rollback |
| L4 material execution | Business approval, monitoring, post-action review |
| L5 irreversible execution | Block by default unless explicitly governed |

## Practical control set

- Use-case risk tier
- Tool authority matrix
- Approval thresholds
- Audit trail
- Exception handling
- Incident response path
- Post-launch review cadence
