# Security Policy

This repository uses synthetic portfolio examples. Do not contribute confidential client data, internal operating procedures, secrets, private prompts, production endpoints, customer identifiers, or regulated data.

## Reporting concerns

Open a GitHub issue for non-sensitive concerns. For sensitive concerns, contact the maintainer through the profile contact channel and avoid posting private details publicly.

## Security principles

- Use anonymized examples
- Do not include credentials or internal system names
- Treat agentic AI use cases as risk-bearing workflows
- Explicitly document approval, audit, and rollback controls for high-risk examples
