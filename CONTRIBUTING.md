# Contributing

This repository is an enterprise agentic AI use-case atlas. Contributions should improve practical decision quality for leaders, architects, and delivery teams.

## Useful contributions

- Add an industry-specific use-case pack
- Improve scoring logic or governance controls
- Add examples of autonomy-level decisions
- Add evaluation criteria for agent workflows
- Improve documentation with pragmatic delivery lessons

## Quality bar

Avoid toy examples. Every contribution should include a business outcome, workflow context, risk consideration, and evaluation approach.

## Validate locally

```bash
pip install -r requirements.txt
pytest -q
python demo/run_demo.py
```
